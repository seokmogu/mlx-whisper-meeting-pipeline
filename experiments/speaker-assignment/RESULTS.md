# Shadow 실험 결과 — 화자 할당·VAD clip·Turbo

- 실행일: 2026-08-20
- 입력: 비공개 18분 33초 회의 음원 1건
- 범위: `experiments/speaker-assignment/out/`에만 파생 산출물 생성
- 외부 전송: 없음
- 운영 코드·전사·회의록·Notion 쓰기: 없음
- 환경: `mlx-whisper 0.4.3`, `pyannote-audio 4.0.4`

한 건의 shadow 결과이므로 운영 승격 근거가 아니라 다음 검증 대상을 좁히는 근거로 사용한다. 정답 화자 라벨과 사람 청취 판정은 아직 없다.

## 1. 화자-단어 할당

현재 운영 함수의 중앙시점 우선 방식을 기준선으로 그대로 import하고, 단어와 화자 구간의 실제 겹친 시간을 합산하는 후보를 비교했다.

| 항목 | 결과 |
|---|---:|
| 합성 경계 fixture | 6/6 통과 |
| 90분 합성 입력 | 10,800단어 / 1,404화자구간 |
| 90분 기준선 → 후보 | 2.368초 → 0.023초, 102배 |
| 실제 exclusive 입력 | 1,927단어 / 351화자구간 |
| 실제 기준선 → 후보 | 0.113초 → 0.004초, 26.9배 |
| 실제 화자 선택 변경 | 14단어 |
| 실제 미할당 | 기준선 12 / 후보 12 |
| 근소한 화자 전환 경고 | 38단어 |
| 일반 diarization의 동시발화 경고 | 178단어 |

판정: **다음 단계 검증 후보**. 속도와 불확실성 표시는 유효하지만, 변경된 14단어의 정답 화자는 음성 청취 전에는 확정할 수 없다. 운영 코드에는 반영하지 않는다.

## 2. VAD clip 전사

Community-1 일반 diarization 발화 구간에 앞뒤 0.25초를 붙이고 0.5초 이하 간격을 합쳐 mlx-whisper `clip_timestamps`로 전달했다.

| 항목 | 전체 전사 | VAD clip |
|---|---:|---:|
| 처리시간 | 80.7초 | 111.8초 |
| 단어 수 | 1,935 | 1,913 |
| 정규화 문자 수 | 5,360 | 5,318 |
| 부정 표현 개수 | 31 | 27 |

- clip은 17개이며 전체 시간의 97.2%를 덮었다.
- 전체 전사의 19단어가 VAD 구간 밖에 있었다.
- 전체 전사 대비 정규화 문자열 유사도는 0.7848이었다.
- 같은 large-v3를 독립 재실행한 대조군 유사도는 0.9973이므로, 0.7848 차이는 일반적인 재실행 변동으로 보기 어렵다.

판정: **현재 구성 기각**. 건너뛸 침묵이 적어 더 느렸고, 단어와 부정 표현이 줄었다. 운영 경로에는 반영하지 않는다.

## 3. large-v3-turbo 전사

같은 음원, 같은 디코딩 설정에서 모델만 `mlx-community/whisper-large-v3-turbo`로 바꿨다.

| 항목 | large-v3 | large-v3-turbo |
|---|---:|---:|
| 처리시간 | 80.7초 | 44.6초 |
| 단어 수 | 1,935 | 1,864 |
| 정규화 문자 수 | 5,360 | 5,591 |
| 숫자 토큰 개수 | 1 | 2 |
| 부정 표현 개수 | 31 | 29 |
| ASCII 용어 개수 | 26 | 26 |

- 속도는 1.81배 빨랐다.
- large-v3 대비 정규화 문자열 유사도는 0.6989였다.
- 같은 모델 재실행 대조군 0.9973보다 차이가 훨씬 크며, 숫자·부정 표현 개수도 달라졌다.

판정: **속도 후보만 유지, 운영 승격 보류**. 최소 5건 고정 평가와 숫자·부정·이름·담당·기한 충돌 구간의 사람 청취가 필요하다.

## 다음 단계

1. 화자 선택이 달라진 14단어와 동시발화 표본을 청취해 정답 라벨을 만든다.
2. 화자 후보가 우세하면 운영 코드가 아닌 별도 shadow transcript 생성기로 5건을 비교한다.
3. Turbo는 같은 5건에서 large-v3와 ABBA 실행하고, 중요 정보 손실이 0일 때만 재검토한다.
4. VAD clip 현재 구성은 추가 실험하지 않는다. 새로운 VAD 방식이나 침묵 비중이 큰 별도 실패 음원이 있을 때만 다시 연다.
